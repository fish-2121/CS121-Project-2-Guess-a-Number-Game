# CS121-Project-2-Guess-a-Number-Game
### This is a game where you guess a random number!
### Here is how the program will work:
- The random number that the user will need to guess will be randomly generated and stored in a variable
- The program will also create a variable to store how many guesses the user has made
- The program will create a keepGoing variable with the value True as a sentinel to stop the while loop
- The program will print into the console asking the user to guess a number
- The user will then input their number into the console, which will add 1 to the guess variable
- The program will check to see if the value is an integer
- If the value is not an integer, the program will ask the user to try again
- If the value is an integer, the program continues
- The program will compare the user's guess to the correct number
- If the user is correct, the program will congratulate the user and say how many guesses it took
- The keepGoing variable will become false which will stop the 
- If the user is incorrect, it will say the user is wrong and continue the loop without changing the keepGoing variable
